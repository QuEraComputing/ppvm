# ppvm-tableau

Generalized stabilizer-tableau simulator for ppvm. `Tableau` handles Clifford circuits; `GeneralizedTableau` adds non-Clifford gates by tracking a sparse vector of coefficients over bitstrings.

Part of [ppvm](https://github.com/QuEraComputing/ppvm), the Programmable Pauli Virtual Machine.

## Usage

```sh
cargo add ppvm-tableau
```

- [Documentation](https://queracomputing.github.io/ppvm/)
- [API reference](https://docs.rs/ppvm-tableau)
