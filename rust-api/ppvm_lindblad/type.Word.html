pub type Word<const C: usize = W_CHUNKS> = PauliWord<[u64; C], FxBuildHasher, true>;
Expand description

The Pauli-word storage type used throughout this crate, C chunks wide.

The crate is const-generic in the chunk count so a register of any size up to MAX_SUPPORTED_QUBITS gets a fixed-size word; the default C = W_CHUNKS covers 128 qubits, byte-for-byte the historical layout. The FxBuildHasher matches the hash used by the FxHashMap keys we wrap with; REHASH=true means set() keeps the cached hash in sync.
