Packed Pauli words, explicit phases, and hashing utilities.

Structs§

PauliKeyColumn
A structure-of-arrays column of PauliWords: parallel X and Z plane blocks plus the shared qubit width.
PauliWord
A Pauli word in packed X/Z planes: I=(0,0), X=(1,0), Z=(0,1), Y=(1,1). A selects backing storage; H selects the internal hash algorithm. Unused bits stay zero; equality compares qubit count and both planes. An eagerly refreshed u64 hash makes lookup a field read and preserves Copy.
Phased
A base word with a phase in {+1, +i, -1, -i}, representing i^φ · g(w). Equality and display include the phase; site inspection uses only the word. Implements neither Hash nor Indexable, so it is not a map key.

Traits§

HashFinalize
Adjusts a structural hash for hash-table lookup according to hasher and width. hashbrown uses low bits for buckets and the top seven bits for control tags. The default leaves the digest unchanged; hashers can override mixing as needed.
PauliStorage
Fixed-size storage for one Pauli bit plane: u64, [u8; N], or [u64; N]. Pod permits safe byte views for hashing; PrimInt enables whole-integer kernels.

DefaultStorage
Default storage is u64, or usize on wasm32 where bitvec lacks u64 support.
