Struct PauliWord 

Source 
pub struct PauliWord<A: PauliStorage = DefaultStorage, H = FxBuildHasher> { /* private fields */ }
Expand description

A Pauli word in packed X/Z planes: I=(0,0), X=(1,0), Z=(0,1), Y=(1,1). A selects backing storage; H selects the internal hash algorithm. Unused bits stay zero; equality compares qubit count and both planes. An eagerly refreshed u64 hash makes lookup a field read and preserves Copy.

pub fn new(nqubits: usize) -> Self

Constructs the identity word on nqubits qubits with zeroed planes. Computes the hash eagerly so the word is ready for map insertion.

pub fn with_bits_toggled( &self, i: usize, toggle_x: bool, toggle_z: bool, ) -> Self

Copies the planes, toggles the requested X/Z bits at i, and hashes once. Builds a rotation-branch key without copying and then replacing the old hash.

Source

pub fn with_bits_toggled2( &self, i: usize, toggle_x_i: bool, toggle_z_i: bool, j: usize, toggle_x_j: bool, toggle_z_j: bool, ) -> Self

Copies both planes once, toggles up to four bits at two sites, and hashes once. Avoids rebuilding the word twice when constructing a two-qubit rotation branch. Keeps direct flips separate from xor_bits2: constant rotation toggles let the compiler remove branches without testing whether storage words coincide.
