Struct Term 

Source 
pub struct Term { /* private fields */ }
Expand description

A symbolic polynomial in sin(x_i) and cos(x_i).

Carries its truncation settings, max_sin (maximum sine degree) and min_eps (largest dropped coefficient magnitude), which every operation applies to its result with the left operand’s settings.

§Examples

use ppvm_sym_2::Var;

// sin²(x0) at x0 = π/2 equals 1.
let expr = Var(0).sin() * Var(0).sin();
let v = expr.eval(&[std::f64::consts::FRAC_PI_2]).unwrap();
assert!((v - 1.0).abs() < 1e-12);

fn mul_sign(&self, sign: i8) -> Self

Flips the stored signs in place (or does nothing for +1); never a Term product. Panics on a bare variable.

Source§

fn magnitude(&self) -> f64

|c| for a constant (including a Sum with no monomials), +∞ otherwise.

So a CoefficientThreshold policy never drops a symbolic coefficient; symbolic terms truncate through max_sin/min_eps instead. This breaks the law N(x) == 0 iff x == 0, but no absolute value exists on this ring, and an ℓ¹ norm (a usable substitute) would start dropping symbolic coefficients.
