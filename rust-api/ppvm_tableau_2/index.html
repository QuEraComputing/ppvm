Hybrid stabilizer simulation: |ψ⟩ = C |χ⟩, an inverse tableau for the Clifford C plus the state |χ⟩ of the virtual qubits in an exchangeable representation.

  • inverse_tableau: InverseTableau and its VirtualView.
  • virtual_state: the VirtualState trait and ActiveDormant, which keeps amplitudes only for the active virtual qubits.
  • generalized_tableau: GeneralizedTableau, the simulator.

RotationCollapse
The change of basis V of a collapse, shared by the tableau (C ← C·V) and the active state (φ ← V† φ), as a gate sequence applied in this order: CX from pivot to every axis in fan_out, CX from every axis in fan_in to pivot, CZ between pivot and every axis in cz, then S, H, X on pivot where set.

A borrowed row: its X words, Z words and sign.
VirtualView
The virtual side of an InverseTableau: row reads and changes of basis C ← C·V, but no physical gates. A virtual state gets this view, so it can change basis together with its own state while |ψ⟩ stays the same.

Traits§

ActiveState
Storage for φ over the active axes 0..k. Only three things happen to it: a Pauli rotation, an activation, and a collapse; every other change of basis is trivial on the state. It sees axes only, never the tableau.
VirtualState
The 2ⁿ-dimensional state |χ⟩ of the n virtual qubits, in a representation of the implementor’s choice.
