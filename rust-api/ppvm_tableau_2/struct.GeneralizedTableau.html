Struct GeneralizedTableau

pub struct GeneralizedTableau<V: VirtualState> { /* private fields */ }
Expand description

The state |ψ⟩ = C |χ⟩: the Clifford C as an InverseTableau, and the virtual state |χ⟩ in the representation V.

Physical gates C ← G·C touch only the tableau. Measurements ask V for the outcome weights, sample here, and let V collapse. Lost and leaked qubits are tracked here; the tableau and V never see them.

impl<V: VirtualState> AsymmetricLossChannel<f64> for GeneralizedTableau<V>

State-dependent loss, with its back-action (issue #249). With Born weights P(m) of Z_q, q is lost from |m⟩ with probability p_m·P(m); otherwise the survival Kraus operator K₀ = √(1−p0)|0⟩⟨0| + √(1−p1)|1⟩⟨1| = a·I + b·Z_q is applied and the state renormalized. On a qubit in superposition K₀ is non-Clifford and activates an axis.

p = [p_LL, p_LQ, p_LN] as the trait documents: if one of the pair is already lost, the other is lost with p[2]; otherwise both with p[0] and each named one alone with p[1]. A leaked partner counts as present.

fn correlated_loss_channel(&mut self, a: usize, b: usize, p: [f64; 3])

Apply correlated loss p = [p_LL, p_LQ, p_LN]: p[0] loses both, p[2] the survivor of an earlier loss. p[1] loses a named one, so exactly one goes with probability 2·p[1] and both remain with 1−2·p[1]−p[0].
