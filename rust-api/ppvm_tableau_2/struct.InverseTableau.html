pub fn measure(&mut self, q: usize, coin: impl FnOnce() -> bool) -> bool

Measure Z_q on C |0…0⟩ and collapse; returns the outcome (true for |1⟩). coin is called only if the outcome is random. See [measure_on] for the method.

Source

pub fn measure_many( &mut self, qubits: &[usize], coin: impl FnMut() -> bool, outcomes: &mut [bool], )

Measure Z_q for each of qubits in order, collapsing after each, and write the outcomes to outcomes. coin is called once per random outcome. Same result as calling measure in order.

With at least TRANSPOSE_THRESHOLD random targets, the batch runs on a column-major copy: two transposes, then each collapse a few words per 64 rows instead of one bit per row.

Source

pub fn collapse_dormant(&mut self, q: usize, active: &QubitMask, m: bool)

Collapse O = C⁻¹ Z_q C onto outcome m on |χ⟩ = |φ⟩ ⊗ |0…0⟩, where φ lives on the active qubits and O has an X or Y on a dormant one.

Stim’s collapse with the pivot p restricted to dormant qubits: p is the lowest of them, CX(p, v) clears every other X (active ones too), and CZ(p, c) clears the Z on every active c. Both are trivial on χ, since p is in |0⟩, so φ is unchanged. What is left is ±X_p or ±Y_p times Z’s on dormant qubits, which act as +1, so the final gates are those of measure.

pub fn reset(&mut self, q: usize, coin: impl FnOnce() -> bool)

Reset qubit q to |0⟩: measure it, then flip it if it was |1⟩.

pub fn change_basis1( &mut self, v: usize, rule: impl Fn(bool, bool) -> ([bool; 2], bool), )

Change the basis of virtual qubit v by the one-qubit Clifford V whose Heisenberg rule is rule: C ← C·V.

Updates the tableau only. The state C (|φ⟩ ⊗ |0…0⟩) stays the same if the caller also applies V† to φ, or if V acts trivially on it (e.g. v dormant and V fixes |0⟩).

Every row R becomes V† R V: the rule runs on each row’s bits in column v. Strided: one word per row.

Used by: dormant-pivot collapse (H on the pivot, X to fix the outcome), active collapse (the final rotation onto Z_h), reset.

Source

pub fn change_basis2( &mut self, a: usize, b: usize, rule: impl Fn([bool; 4]) -> ([bool; 4], bool), )

Change the basis of virtual qubits a, b by the two-qubit Clifford V whose Heisenberg rule is rule (a is the control for controlled gates): C ← C·V. Same contract as change_basis1.

Used by: T-gate localization (CX(p, v) collects the X bits of O onto the pivot p), dormant-pivot collapse (CX(p, v), CZ(p, c)), active collapse (the CX / CZ that reduce P to one qubit).

Source

pub fn fan_out( &mut self, pivot: usize, cx_targets: &[usize], cz_targets: &[usize], last: impl Fn(bool, bool) -> ([bool; 2], bool), )

Change basis by a pivot fan-out in one pass over the rows: C ← C·V with V = CX(p, t₁)⋯CX(p, t_k) · CZ(p, c₁)⋯CZ(p, c_m) · L(p), where L is the one-qubit Clifford whose Heisenberg rule is last.

Same result and contract as the corresponding change_basis2 / change_basis1 calls in that order, but each row loads and stores the pivot’s bits and its sign once instead of once per gate. Targets must be distinct and differ from the pivot.

Used by: T-gate localization (CX only, last the identity), both random measurement collapses (CX, CZ, then H/S·H and an X).
