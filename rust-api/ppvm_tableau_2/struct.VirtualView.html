Struct VirtualView 

Source 
pub struct VirtualView<'a> { /* private fields */ }
Expand description

The virtual side of an InverseTableau: row reads and changes of basis C ← C·V, but no physical gates. A virtual state gets this view, so it can change basis together with its own state while |ψ⟩ stays the same.

pub fn iz_product(&self, qubits: &[usize]) -> OwnedRow

O = C⁻¹ (∏ Z_q) C = ∏ iz_q over qubits, which must be distinct. The Z_q commute, so O is a Hermitian Pauli string with sign ±1.
