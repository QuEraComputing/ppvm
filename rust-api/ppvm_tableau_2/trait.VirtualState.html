Expand description

The 2ⁿ-dimensional state |χ⟩ of the n virtual qubits, in a representation of the implementor’s choice.

It sees the tableau only through a VirtualView: it may change basis (C ← C·V with χ ← V† χ, so |ψ⟩ is unchanged), but never applies a physical gate. Arguments are physical qubits; the implementor reads O = C⁻¹ Z_q C from the view. The caller samples outcomes, so weights are unnormalized and rotate need not be unitary.

fn z_weights(&mut self, t: &mut VirtualView<'_>, q: usize) -> [f64; 2]

Unnormalized weights of the outcomes 0 and 1 of Z_q. Takes &mut so an implementor may change basis here and reuse it in collapse.

Source

fn collapse(&mut self, t: &mut VirtualView<'_>, q: usize, m: bool)

Project onto outcome m of Z_q and renormalize. The outcome must have nonzero weight.

fn is_zero(&self) -> bool

Whether χ = |0…0⟩, so |ψ⟩ = C |0…0⟩ is a stabilizer state and the caller may measure on the tableau alone. false is always correct.
