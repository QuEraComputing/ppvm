Expand description

Single-qubit leakage channel — with probability p0 the qubit is leaked and pinned to |0⟩, with probability p1 leaked and pinned to |1⟩. Unlike LossChannel, a leaked qubit remains measurable and returns the pinned computational bit; gates still skip it.
