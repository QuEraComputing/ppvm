Module algebra 

Source
Expand description

Algebra capabilities: key products, coefficient conjugation, and imaginary units. Phase carries the residual fourth root of unity emitted by a key product.

Enums§

Phase
A fourth root of unity iᵏ, with k modulo four. KeyProduct::key_mul returns this residual phase for the coefficient to absorb.

Traits§

Conjugate
A commutative ring involution used by crate::containers::Pair::hermitian_overlap. Requires conj(conj(a)) == a, preservation of addition and multiplication, and conj(i) == -i when the ring also implements ImaginaryUnit.
ImaginaryUnit
A commutative coefficient ring with an imaginary unit. Implementations must satisfy Self::imaginary_unit() * Self::imaginary_unit() == -Self::one(), hence i⁴ = 1.
KeyProduct
A key product returning a key and residual phase i^{β(u,v)}. Key multiplication must be associative, and phases must satisfy the cocycle law: β(u,v) + β(u·v,w) == β(v,w) + β(u,v·w) modulo four.
