Expand description

Accumulate linear combinations and explicitly reduce exact-zero coefficients.

Required Methods§

Source

fn accumulate_batch(&mut self, terms: &TermBatch<Self::Key, Self::Coeff>)

Merge a batch, adding to existing keys or inserting new ones. The algebraic multiset contract permits reordering and partitioning; floating-point accumulation can still differ through rounding.

Source

fn reduce(&mut self)

Canonicalize to reduced finite-support form: drop every key whose coefficient is_zero(). First-class and run only at finalize — never inline during accumulation.

fn accumulate_batch(&mut self, terms: &TermBatch<K, C>)

Linear-scan hash-join: for each produced term, find the matching key and add onto it, else append. O(n·m) in the support size, which is the right cost model for the small support this backend targets.
