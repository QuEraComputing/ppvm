Expand description

Read and value-producing operations on a structure-of-arrays key column, generic over the key type. Pauli/loss row accessors live in PauliColumn and LossColumn; construction and mutation in KeyColumnMut.

fn len(&self) -> usize

Number of keys currently in the column.

Source

fn capacity(&self) -> usize

Number of keys the existing plane allocations can hold without growing.

Source

fn hash_into(&self, out: &mut [u64])

Bulk structural hash of the whole column into a parallel hash column. out[i] must equal the i-th key’s Indexable::key_hash.

Source

fn key_eq(&self, i: usize, other: &Self::Key) -> bool

Join confirm: compare element i against a build-side key after a hash or tag match, without materializing the whole element.

Source

fn gather(&self, indices: &[u32]) -> Self

Select or permute elements into a new column (radix partitioning, compaction, device staging). Operates plane by plane, never scalar.

Source

fn get(&self, i: usize) -> Self::Key

Scalar materialization of one element — a naive backend’s fallback, never the hot path.
