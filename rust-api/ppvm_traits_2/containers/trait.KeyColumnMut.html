Expand description

Construction and mutation of a KeyColumn.

Required Methods§

Source

fn with_capacity(n: usize) -> Self

Create an empty column with capacity for n keys.

Source

fn push(&mut self, key: Self::Key)

Append one key while keeping each plane contiguous.

Source

fn clear(&mut self)

Clear the column while retaining its backing allocations.

Source

fn set(&mut self, i: usize, key: Self::Key)

Overwrite element i, preserving other elements and backing allocations. Panics (or debug-panics) if i >= len().

Source

fn truncate(&mut self, len: usize)

Shorten to len elements, keeping the backing allocation. A no-op if len >= self.len(). The tail step of a stable retain compaction (set the survivors down, then cut).

Provided Methods§

Source

fn reserve(&mut self, _additional: usize)

Reserve room for additional keys while retaining existing entries. The default is a no-op for backends without reservation support.

Source

fn swap_remove(&mut self, i: usize) -> Self::Key

Remove row i by moving the final row into its slot.
