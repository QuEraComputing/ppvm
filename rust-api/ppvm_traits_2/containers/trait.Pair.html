Expand description

Pair supports: overlap computes Σ a_k b_k without conjugation. hermitian_overlap computes Σ conj(a_k) b_k and requires Conjugate. For Pauli coefficients, the bilinear pairing is the normalized trace Tr(A B)/2ⁿ.
