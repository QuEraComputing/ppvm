Expand description

A finitely supported map from keys to coefficients. Read-only export avoids requiring mutable pair slots in columnar backends.

Required Associated Types§

The coefficient ring.

fn iter(&self) -> impl Iterator<Item = (Self::Key, Self::Coeff)>

Read-only export of the support as (key, coeff) pairs. A SoA backend synthesizes the pairs from its columns.

Provided Methods§

Source

Whether the support is empty.

Source

fn for_each_ref(&self, f: impl FnMut(&Self::Key, &Self::Coeff))

Visit each supported key and coefficient by reference, in backend order. The default materializes owned pairs through Self::iter; stored backends should override it to avoid cloning coefficients before filtering.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
