Expand description

Two-qubit rotations exp(-i θ/2 · P_a ⊗ P_b).

Required Methods§

Source

fn rotate_2( &mut self, axis_a: Pauli, axis_b: Pauli, a: usize, b: usize, theta: A, )

Rotate about the supplied Pauli axes.

The generator is axis_a ⊗ axis_b on sites a and b.
