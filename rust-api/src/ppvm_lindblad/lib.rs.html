4//! Direct Heisenberg-picture Lindbladian evolution on an adaptive
5//! Pauli-string basis.
6//!
7//! For a Hermitian Pauli Hamiltonian `H = Σ c_i P_i` and jump operators
8//! `L_k = Σ_a λ_{k,a} P_{k,a}` (each a Hermitian-Pauli linear combination
9//! with possibly complex coefficients) with rates `γ_k ≥ 0`, the adjoint
10//! Lindbladian acts on a single Pauli string `p` as
11//!
12//! ```text
13//! L*(p) = i [H, p] + Σ_k γ_k ( L_k† p L_k − 1/2 {L_k† L_k, p} ).
14//! ```
15//!
16//! Two jump shapes are supported with separate code paths:
17//!
18//! - **Hermitian Pauli** (`L = P`, `λ ∈ ℝ`): the dissipator collapses to a
19//!   diagonal `-2γ` on Pauli strings that anti-commute with `P`. Same fast
20//!   path used by every dephasing-style model.
21//!
22//! - **General** (complex `λ_a`, e.g. `σ± = (X ± iY)/2`): the dissipator
23//!   becomes a double sum `Σ_{a,b} λ_a* λ_b P_a p P_b` plus a Pauli-
24//!   linear-combination anti-commutator with `L†L`, which is precomputed
25//!   once at construction. Intermediate coefficients are complex; the
26//!   result is real because `L*` preserves Hermiticity, so we cast back
27//!   to `f64` at the boundary (with a debug-only check that `|Im|` is at
28//!   FP noise).
29//!
30//! Pauli strings are stored as [`ppvm_pauli_word::word::PauliWord`] backed by
31//! a fixed array of `C` chunks (64-bit, or 32-bit on 32-bit targets) with
32//! cached hashes for fast HashMap lookup. The crate is const-generic in `C`
33//! ([`Word`], [`LindbladSpec`]); the default is the 128-qubit width,
34//! and [`chunks_for`] picks the narrowest of the 128/256/512-qubit widths
35//! for a register. The hot-path commutator/
36//! product loops bypass the higher-level word API and operate directly on
37//! the raw chunks for speed.
