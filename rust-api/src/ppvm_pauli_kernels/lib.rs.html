4//! Bit-level Pauli kernels shared by every PPVM container that conjugates or
5//! multiplies Pauli operators.
6//!
7//! - [`heisenberg`]: one Boolean update rule per Clifford gate, in the
8//!   Heisenberg picture `P ↦ G† P G` (so `heisenberg::s` computes `S† P S`).
9//!   A rule maps the pre-gate X/Z bits of a Pauli to its post-gate bits and a
10//!   sign-flip mask. It is generic over [`Bits`], so the same formula updates
11//!   one Pauli (`bool`) or 64 at once (`u64`, one per bit position).
12//! - [`row_product`] / [`row_product_phase`]: the packed Pauli-word product and
13//!   the exponent `k` of the phase `iᵏ` it emits, built on the per-word
14//!   [`word_product`].
15//!
16//! The crate has no PPVM dependencies; containers wire the rules into their own
17//! loops.
18//!
19//! # Verification
20//!
21//! The formulas are proved in `lean/PPVM/Kernels/` against exact Gaussian-integer
22//! matrices: each rule equals `G† P G` for its gate, and the product phase
23//! equals the matrix product's. The tests in `tests/` compare the Rust code
24//! against tables generated from that matrix model. `lean/README.md` lists
25//! what is not covered by the proofs.
26
