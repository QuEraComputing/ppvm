4//! The inverse stabilizer tableau `C⁻¹` of a Clifford `C`.
5//!
6//! Row `ix_q` is `C⁻¹ X_q C` and row `iz_q` is `C⁻¹ Z_q C`, each stored as
7//! packed X and Z bits plus one sign bit (rows are Hermitian, so their phase
8//! is ±1). Rows are indexed `ix_q = q`, `iz_q = n + q`.
9//!
10//! - `data`: the storage, row reads, and where rows sit in the arena.
11//! - `bitword`: the storage word; the only code that knows its width.
12//! - `physical_gates`: physical gates `C ← G·C`, which mix rows.
13//! - `virtual_gates`: changes of basis `C ← C·V`, which rewrite columns.
14//! - `measure`: Z measurement and reset of the stabilizer state.
15//! - `transposed`: a column-major copy for batches of changes of basis.
16//! - `view`: [`VirtualView`], the virtual side handed to a virtual state.
17//!
18//! Where rows sit in the arena is decided only in `data`: by `offsets` (used
19//! by `x_at`, `z_at`) and by `for_each_row`, which walks the same blocks.
20
